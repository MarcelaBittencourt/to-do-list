# Relato rápido — Teste Inicial Climba

## Como me organizei para entregar o teste

Primeiramente, analisei os requisitos da aplicação e dividi o desenvolvimento em pequenas etapas: estrutura do projeto, criação do banco de dados, desenvolvimento da API, criação da interface, integração entre front-end e back-end, validações e testes das funcionalidades.

Optei por manter uma solução simples e coerente com meu nível atual de conhecimento, priorizando código organizado, funcionamento das funcionalidades solicitadas e facilidade de manutenção.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Node.js
- Express
- PostgreSQL
- Git e GitHub

## Uso de IA

Utilizei uma ferramenta de inteligência artificial como apoio durante o desenvolvimento, principalmente para esclarecer dúvidas, discutir decisões de implementação, revisar trechos de código e ajudar a identificar possíveis melhorias. As soluções foram analisadas e adaptadas ao projeto, buscando compreender o funcionamento de cada parte da aplicação.

## Decisões relevantes

Escolhi uma arquitetura simples em que o front-end faz requisições HTTP para uma API REST desenvolvida com Node.js e Express. O PostgreSQL foi utilizado para persistir as tarefas.

A aplicação possui operações de criação, leitura, atualização, exclusão e pesquisa de tarefas, além das validações solicitadas no teste.
